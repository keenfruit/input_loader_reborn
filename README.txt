# Input Loader Reborn - Source

This is the source code corresponding to Input Loader Reborn v1.0.

## Purpose

Input Loader Reborn is a Cyberpunk 2077 mod that loads inputs that are required for other mods to work. Input Loader is the original version made by user Jack Humbert, but the mod stopped working for me and many users after game version 2.31. I used AI to create a updated version that simply works on the latest version.

## AI Assistance

AI tools were used during development for coding assistance, debugging,
research, and code review.

The released mod was tested in-game by the author.

## Source Review

This source is being provided for moderator/security review.

There is no intentionally malicious functionality in the mod.

## Dependencies

- RED4ext
- pugixml 1.14

## Building

1. Install Visual Studio with Desktop development with C++.
2. Install/configure the required dependencies.
3. Open the project/solution.
4. Build Release x64.
